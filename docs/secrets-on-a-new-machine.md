# Getting the secrets on another machine

No secret is stored in this repository. On a new machine you **generate** the local secrets instead of copying them. The only values you fetch from outside are the Clerk keys.

## What each secret is and where it comes from

| Secret | Where it lives | How to get it on a new machine |
|---|---|---|
| `NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY`, `CLERK_SECRET_KEY` | `.env.local` | Clerk dashboard → your app → **API keys** |
| `CLERK_JWT_ISSUER_DOMAIN` | `.env.local` → Convex env | Clerk dashboard → **API keys** → Frontend API URL |
| `NEXT_PUBLIC_CONVEX_URL`, `NEXT_PUBLIC_CONVEX_SITE_URL` | `.env.local` | Written by `npx convex dev --once` |
| `LENDLOOP_WEBHOOK_SECRET`, `LENDLOOP_AUTOMATION_SECRET` | `.env` + Convex env + n8n credentials | Generated by `npm run setup` |
| `.secrets/n8n_encryption_key` | file, mounted as a Docker secret | Generated by `npm run setup` |

## Steps

```bash
git clone https://github.com/RoniedsonSouza/lendloop.git
cd lendloop
npm ci
```

1. **Clerk keys.** Sign in to the [Clerk dashboard](https://dashboard.clerk.com) and open the same application, or create a new one with the setup from README → Quick start. Copy the keys **straight into** `.env.local`:
   ```bash
   NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY=pk_test_...
   CLERK_SECRET_KEY=sk_test_...
   CLERK_JWT_ISSUER_DOMAIN=https://<your-app>.clerk.accounts.dev
   NEXT_PUBLIC_APP_TIMEZONE=America/Sao_Paulo
   ```
2. **Convex (local).** Run `npx convex dev --once` and choose "Start without an account". This creates a new local deployment and adds the Convex URLs to `.env.local`.
3. **Generated secrets.** Run `npm run setup`. It:
   - creates `.env` (mode 0600) with fresh HMAC secrets;
   - creates `.secrets/n8n_encryption_key` inside a 0700 folder;
   - sets the Convex env, including the Clerk issuer.

   Existing values are kept, so running it twice is safe.
4. **n8n.** Run `docker compose up -d`. The import container encrypts the secrets into n8n credentials.

## Good practices

- **Never send secrets** by chat, e-mail, issue, commit or screenshot. If one leaks, rotate it: create new keys in Clerk, or delete `.env` / `.secrets/` and run `npm run setup` again.
- **Don't copy `.env` or `.secrets/` between machines.** Each machine has its own local Convex deployment and its own n8n volume, so fresh secrets work and nothing is shared.
- **Changed the n8n encryption key?** Credentials already saved in the old `n8n_data` volume can't be decrypted. Reset with `docker compose down -v`, then run `docker compose up -d` again.
- **Moving an existing n8n volume** to another machine is the only case where you need the same `n8n_encryption_key`. Transfer it through a password manager, never in plain text.
- **Local data is not synced.** Users and loans live in each machine's local Convex. Use `npx convex run seed:demo '{"email":"you@example.com"}'` to get demo data again.
